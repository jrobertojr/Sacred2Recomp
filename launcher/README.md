# Sacred2Recomp Launcher
Experimental Windows .NET 8 WinForms launcher. Select an ISO or extracted directory, then generate native code and build in an isolated LocalAppData directory. The bar reports completed stages, not estimated compilation percentages. Requires ReXGlue 0.11.0, extract-xiso (for ISO), CMake, Ninja, Clang and a configured Windows C++ development environment. Tools are resolved from the existing local work/tools directory or PATH. The source project must be available beside or above the launcher. This is an early implementation; clean installation, runtime patch integration, title identity verification and gameplay are not validated. No game data is bundled.
